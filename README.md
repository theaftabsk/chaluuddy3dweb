# Chalobuddy 3D Web Landing Page

An ultra-premium, interactive 3D travel community landing page built with React 19, TypeScript, Vite, Three.js, GSAP ScrollTrigger, and Lenis smooth scroll.

## ✨ Features

- **Liquid Glass Floating Navbar**: Frosted glassmorphism dock with brand emblem, navigation links, and action buttons. Fully responsive with mobile drawer menu.
- **Cinematic Scroll-Driven Hero Journey**: 40-frame sequential animation synchronized with GSAP ScrollTrigger, transitioning through:
  - *Stage 1: Hero* – "Find Your People. Explore The World." with verified traveler trust capsule.
  - *Stage 2: How It Works* – "Three Simple Steps" with glowing neon frosted glass cards.
  - *Stage 3: The Chalobuddy Advantage* – 6-feature grid highlighting smart matchmaking and trip discovery.
- **Interactive 3D Photorealistic Earth**: High-resolution Three.js Earth with dynamic day/night light emission, atmospheric Rayleigh scattering, animated 3D orbital flight ring with plane, and 6 floating global destination cards with glowing curved connector lines.
- **Final Adventure CTA**: Panoramic alpine adventure landscape with custom call-to-action buttons.
- **3D Illustrated Footer**: Multi-column footer featuring 3D travel illustration and organic wave divider.
- **100% Mobile Responsive**: Optimized for all screen sizes from mobile phones (320px+) to 4K displays.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/theaftabsk/chaluuddy3dweb.git

# Navigate to project folder
cd chaluuddy3dweb

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **3D Graphics**: Three.js
- **Animations**: GSAP + ScrollTrigger
- **Smooth Scrolling**: Lenis
- **Icons**: Lucide React
- **Styling**: Modern CSS / Glassmorphism
